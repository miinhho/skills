This folder is the entire offline project. Python 3.10+ and the standard library are sufficient. No dependencies, services, user data, or network access are needed.

render_labels(records, prefix='') is the supported public API. It lazily yields labels in input order, without mutating records or eagerly consuming the source. Recipient whitespace is stripped. The exact string is prefix + stripped recipient + ' | ' + service display + ' | ' + decimal weight + 'g'. The service display is EXPRESS only for service == 'express'; all other service strings display STANDARD. Prefix is used literally. Records are trusted dictionaries with string recipient/service and integer weight_grams; missing keys still raise KeyError during iteration, not iterator construction. Empty input yields nothing. consumer.manifest_text and consumer.preview_label are supported actual consumers. Underscore helpers have no supported external callers or dynamic discovery.
